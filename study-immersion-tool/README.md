# 몰입 - 나만의 공부 몰입 툴

혼자 공부할 때 집중을 도와주는 개인용 웹앱입니다. Flask 백엔드 + 바닐라 JS 프론트엔드로,
외부 오디오 파일이나 CDN 없이 동작합니다 (집중 사운드는 브라우저에서 실시간 생성).

## 기능

- **뽀모도로 타이머**: 집중/휴식/긴 휴식 시간을 자유롭게 설정, 4세션마다 자동으로 긴 휴식
- **집중 사운드**: 화이트노이즈 / 핑크노이즈 / 브라운노이즈를 Web Audio API로 즉석 생성
- **오늘의 학습목표**: 하루 목표를 적어두고 자동 저장
- **할 일(할당량) 체크리스트**: 오늘 해야 할 일을 추가/체크/삭제
- **연습장**: 자유 메모, 자동 저장
- **오늘의 피드백**: 하루를 마무리하며 회고 기록
- **공부 기록 및 통계**: 완료한 뽀모도로를 SQLite에 기록하고 최근 7일 집중 시간을 그래프로 표시

## 실행 방법

```bash
cd study-immersion-tool
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:5050 접속.

첫 실행 시 `study.db` (SQLite)가 자동 생성되며, 모든 기록은 로컬에만 저장됩니다.
